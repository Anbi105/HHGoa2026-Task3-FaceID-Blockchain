# Fully pinned dependency set for a clean clone.
#
#   pip install -r requirements.lock.txt
#
# Two halves, both taken from real working environments — nothing invented:
#
#   Stage 1 (probe)        InsightFace / ONNX / OpenCV model stack.
#   Stage 3 (attestation)  web3 + eth-* tree, frozen from the .venv the test
#                          suite actually passes in.
#
# Python 3.11-3.12.  numpy is pinned <2 deliberately: InsightFace 0.7.3 and
# several faiss-cpu builds are compiled against the numpy 1.x ABI and fail at
# import time against numpy 2 (guide §4).  numpy 1.26.4 publishes no cp313
# wheel, which is why 3.13 is out of range rather than numpy 2 being pinned in.
#
# VERIFIED: `pip install -r requirements.lock.txt` resolves all 88 pins on
# CPython 3.11.  insightface and stringzilla ship no Windows wheels and build
# from source, so a Windows install additionally needs MSVC C++ Build Tools;
# Linux/CI has a toolchain and needs nothing extra.
#
# Platform-specific wheels (e.g. pywin32) are intentionally not pinned here.
